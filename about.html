Solar System Explorer

An interactive 3D website where you can spin the Sun, all eight planets and a black hole, and read what makes each one special. I built it for myself, because I love exploring the solar system.

Open live demo See what's next

Why I made it

I have always been curious about space, so I started this project to learn about the solar system in a way that feels like exploring, not just reading. It is not finished yet. I am still adding things and improving it whenever I have time, so some parts may change or be rough for now.

What it does today

Real 3D planets

Textured spheres built from NASA-based imagery. Drag to rotate them in any direction.

10 objects to explore

The Sun, 8 planets and a black hole, each with its own description.

Quick facts

Distance, moons, diameter, day length, year length and temperature for each one.

Works on phones

Responsive layout that adapts to small screens.

Built with

HTMLCSSJavaScriptThree.js (WebGL)NASA-based textures
