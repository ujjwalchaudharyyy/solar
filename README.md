# Solar System Explorer 🪐

An interactive 3D website to explore the Sun, the 8 planets and a black hole. Drag to rotate each one and read key facts about it.

**Status: work in progress.** I'm building this for myself because I love exploring the solar system.

## Pages
- `index.html` – the 3D solar system explorer
- `about.html` – project explanation and roadmap

## Built with
HTML, CSS, JavaScript, [Three.js](https://threejs.org/) (WebGL)
